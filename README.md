# Proyecto Final: Sistema de Control Ciudadano (COPACI)
**Materia:** Construye Aplicaciones Web  
**Alumno:** Santiago Reséndiz Sánchez  

## 📌 Descripción del Proyecto
Plataforma web para la gestión comunitaria digital del COPACI. Permite a los vecinos solicitar constancias de residencia con acuse digital y reportar fallas en luminarias y bacheo, además de ofrecer un panel administrativo para actualizar los estatus en tiempo real con persistencia en LocalStorage.
